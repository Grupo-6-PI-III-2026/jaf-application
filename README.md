# Aplicação JAF!
Sistema geral do projeto para a JAF

## Melhorias do beneficiário

- [Funcionalidades, regras e validações da entrega](docs/MELHORIAS-BENEFICIARIO.md)
- [Contrato das APIs financeiras, reembolsos e presenças](jaf-backend/API-FINANCEIRO.md)

A aplicação local fica em http://localhost. No VS Code, execute a tarefa
**JAF: iniciar aplicação** para construir e subir os serviços ou
**JAF: validar melhorias** para executar os testes, build e lint.

Recebido acumulado, total gasto e saldo da obra são exclusivos de ADMIN.
Reembolsos têm pagamentos parciais e histórico por gasto; presenças são
registradas manualmente por usuários autorizados.
